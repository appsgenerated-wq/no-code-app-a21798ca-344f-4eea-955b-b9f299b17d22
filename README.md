# FlavorFind - Food Discovery App

Welcome to FlavorFind, a complete full-stack application built with React and a Manifest backend. This app allows users to discover restaurants and browse their menus. Restaurant owners can sign up and manage their own restaurant listings and dishes.

## Features

- **User Authentication**: Secure sign-up and login for users.
- **Restaurant Browsing**: Publicly accessible list of all restaurants.
- **Menu Viewing**: View detailed menus for each restaurant.
- **Restaurant Management**: Authenticated users can create their own restaurant listings.
- **Dish Management**: Restaurant owners can add, update, and remove dishes from their menus.
- **Ownership Control**: Policies ensure users can only edit the restaurants and dishes they own.
- **Admin Panel**: A complete backend admin interface for managing all data.

## Tech Stack

- **Backend**: Manifest
- **Frontend**: React, Vite, Tailwind CSS
- **SDK**: `@mnfst/sdk` for all backend communication
